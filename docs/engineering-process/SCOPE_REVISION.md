# Focused scope addendum

Formal identity remains **EIMS — Enterprise Infrastructure Management System**. Study/evaluation scope: **Log Investigation & Evidence Review**.

Problem hypothesis: infrastructure engineers need to establish what logs actually show, locate supporting source evidence, understand remaining uncertainty and retrieve prior investigations. The student reports Windows, Veeam and firewall scenarios from workplace observation; these are not formal interview findings.

Primary workflow: Provide Logs → Identify Source → Extract Evidence → Present Findings → Verify Original Evidence → Save/Review History.

Core: supported log input, source qualification, observed evidence, original file/line provenance, bounded diagnostic references/uncertainty and history. Supporting: USB Auditor → JSON → Endpoint Import → asset/event records; inventory and observability. Legacy/needs review: standalone Analyzer client versus integrated dashboard. Outside this evaluation: OCR asset registration and broader compliance/discovery features. Preserve all existing modules; no removal or wholesale architecture rewrite is justified.

Correctness boundaries: event 41 alone does not prove power outage; file access does not prove exfiltration; deny does not prove attack; shared identifiers do not prove causality; confidence is not root-cause confirmation. Missing evidence is disclosed. External AI is optional and is not an authority over observed evidence.

Original PRD remains historical and authoritative for its original enterprise scope; this addendum defines the narrower study requirements. Final scope needs confirmation from the engineer and academic adviser.
