# Short post-task questionnaire

After each task: How easy was this task? 1 = very difficult, 7 = very easy; optional no response. How sure are you that you found the supporting evidence? 1 = not sure, 7 = very sure. What was confusing? What would you change first? Do you distinguish observed evidence from a possible explanation? Ask for an example without prompting the expected answer.

After all tasks: Which part would help your normal investigations? Which inputs or evidence are missing? Would you need changes before using it with permitted real data? Do not collect secrets or incident details. This short questionnaire is a project-specific instrument, not a validated SUS score or ISO-compliance measure.
