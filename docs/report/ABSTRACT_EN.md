# Abstract

Enterprise infrastructure management across segmented corporate networks is frequently challenged by distributed compute assets, air-gapped network enclaves, and fragmented operational evidence. When infrastructure failures occur on hosts lacking persistent monitoring agents, administrators face labor-intensive, ad-hoc diagnostics that lack structured traceability. This project presents the Enterprise Infrastructure Management System (EIMS), an integrated infrastructure evidence management and artificial intelligence (AI)-assisted investigation platform designed to bridge connected operations and air-gapped endpoints. EIMS combines a centralized PostgreSQL asset registry with an episodic, portable evidence collection utility built on an embedded CPython 3.14.3 runtime. The collector executes non-destructive Windows Management Instrumentation (WMI) queries and extracts Windows Event Log records, specifically scoped to the System and Application channels over a 24-hour window with a default maximum of 500 events across the combined query, into structured, schema-validated offline JSON artifacts. Upon central ingestion, EIMS enforces application-level sequential deduplication via SHA-256 event fingerprinting and prioritizes critical occurrences. To accelerate administrative triage without autonomous overreach, a bounded AI analyzer evaluates at most ten prioritized events per import using semantic embeddings (FastEmbed `BAAI/bge-small-en-v1.5`, with SentenceTransformer `all-MiniLM-L6-v2` fallback) and retrieval-augmented generation, persisting diagnostic findings as auditable AnalysisHistory records linked to the asset. System verification encompassed automated testing, historical field imports, and live downstream validation. The hermetic Sprint 13 ingestion test suite achieved 37 passed tests (0 failed, 4 warnings), while frontend TypeScript and production builds executed cleanly. The field-validated dataset confirmed 49 persisted Windows Event Evidence records (34 System, 15 Application), yielding 10 bounded AnalysisHistory records for the evaluated host (`ASSET-01`). The asset-filtered history API returned an HTTP 200 response, and live browser testing successfully validated the end-to-end presentation of event evidence and AI findings (A9 PASS). Previous field validation demonstrated the portable acquisition and sequential import workflow, while the latest on-site verification confirmed the downstream persisted evidence, analysis history, filtered API, and browser presentation. EIMS proves the engineering feasibility of traceable, air-gapped evidence management and assistive AI diagnostics within a well-defined academic prototype baseline, distinct from a production-hardened or forensic system.
